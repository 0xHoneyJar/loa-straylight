## Rule

Research handoffs stress-test Straylight. They do not define implementation by themselves.

Repo verification defines what exists today. It does not automatically assign Straylight primitive ownership.

Implementation must be derived through PRD, SDD, sprint plan, review, and explicit repo verification.
